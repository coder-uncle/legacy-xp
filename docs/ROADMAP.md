# Roadmap

## Initial foundation
- Desktop shell, Start menu, taskbar, clock and context menu.
- Window lifecycle: open, focus, move, resize, minimize, maximize, restore and close.
- Notepad, Calculator, Paint, virtual Explorer, Run and About.
- Browser persistence for notes, wallpaper and virtual file listing.

## Full WinXP.si parity still outstanding
The reference capture identified 61 window registrations and 65 lazy chunks. This is a research inventory, not proof those programs exist in this repository.

- Boot/logon, user switching, shutdown/restart, full shell menus and tray flyouts.
- Themes, desktop icon arrangement, screen savers and sound schemes.
- IndexedDB virtual drives, files/blobs, Recycle Bin, clipboard and file associations.
- Registry, Control Panel, Display, Mouse, Keyboard, Date/Time and Power tools.
- WordPad, Command Prompt, Task Manager, Registry Editor and browser viewer.
- Outlook Express, Messenger/QQ, Winamp and Windows Media Player experiences.
- Minesweeper, Solitaire, Spider, FreeCell, Hearts and Pinball.
- Programs directory, individual pages, FAQ, deep links and SEO.
- Offline PWA, accessibility, tests and browser compatibility.

## Safety
Keep file operations virtual by default. Never access user-selected real folders without an explicit permission flow. Redistribute artwork, sounds and third-party assets only where their licences permit.
